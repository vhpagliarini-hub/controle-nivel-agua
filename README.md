# Controle de Níveis de Água

Projeto em Python para simular o monitoramento dos níveis de água de um reservatório.

## Tecnologias utilizadas
- Python
- Biblioteca Colorama

## Funcionalidades
- Armazenamento dos níveis em uma lista.
- Função para selecionar a cor conforme o nível.
- Exibição de mensagens coloridas no terminal.
- Restauração do estilo padrão após as mensagens.

## Como executar
1. Instale `pip install -r requirements.txt`.
2. Após a instalação, execute o programa com `python app.py`.
